# «МОЯ ПЛАНЕТА» — анимация логотипа

8 секунд, 30 fps, белый фон. Есть две версии.

## 3D-версия (основная)

| Файл | Что это |
|---|---|
| `moya-planeta-3d-1920x1080.mp4` | видео 16:9 |
| `moya-planeta-3d-1080x1080.mp4` | видео 1:1 |
| `moya-planeta-logo-3d.html` | живой плеер на WebGL (three.js), всё встроено в один файл |

Все элементы — объёмные модели со светом и мягкой тенью: контур метки, линии, треугольники, буквы и силуэт туриста выдавлены в глубину. Голубой круг — настоящая сфера. В начале и в конце она сплющена в диск, а в середине раскрывается в глобус.

- **0.0–1.6 с** — элементы вылетают из глубины сцены на зрителя, вращаясь в трёх осях. Каждый проскакивает чуть ближе своего места и встаёт на него. Мимо камеры пролетают объёмные осколки.
- **0.65–1.8 с** — объёмный контур метки вырастает по кругу.
- **1.75–4.2 с** — диск раздувается в шар-глобус с материками и меридианами, вращается и снова сплющивается в диск.
- **2.6–4.45 с** — объёмный турист поворачивается к зрителю примерно на 35° и возвращается.
- **4.05–5.6 с** — 3D-буквы «МОЯ ПЛАНЕТА» прилетают по одной: каждая крутится, уменьшается и встаёт в строку между линиями.
- **6.0–7.1 с** — по всему логотипу слева направо проходит белый глянцевый блик.
- Камера статичная и фронтальная. Сам логотип плавно доворачивается из ракурса в спокойный финальный, где видна толщина элементов.

## 2D-версия (плоская, с 3D-вставками)

`moya-planeta-1920x1080.mp4`, `moya-planeta-1080x1080.mp4`, `moya-planeta-logo.html`.

## Пересборка видео

```
node render.js moya-planeta-logo-3d.html 1920 1080 moya-planeta-3d-1920x1080.mp4 3
node render.js moya-planeta-logo.html    1920 1080 moya-planeta-1920x1080.mp4    6
```

Нужны Playwright и ffmpeg. Последний аргумент — сколько подкадров смешивать для размытия движения.
В плеере размер задаётся так: `moya-planeta-logo-3d.html?w=1080&h=1350`.

Силуэт туриста трассирован в вектор из исходного логотипа. Надпись набрана шрифтом Roboto Slab, глифы встроены как векторные контуры.
