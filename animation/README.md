# «МОЯ ПЛАНЕТА» — анимация логотипа

8 секунд, 30 fps, белый фон.

| Файл | Что это |
|---|---|
| `moya-planeta-1920x1080.mp4` | видео 16:9 |
| `moya-planeta-1080x1080.mp4` | видео 1:1 |
| `moya-planeta-logo.html` | живой плеер с ползунком; шрифт и векторы встроены |
| `render.js` | рендер кадров через Playwright и сборка MP4 через ffmpeg |

Пересобрать: `node render.js 1920 1080 out.mp4` (нужны Playwright и ffmpeg).
В плеере размер задаётся так: `moya-planeta-logo.html?w=1080&h=1350`.

## Раскадровка
- **0.0–1.6 с** — голубые и белые элементы вылетают из глубины на зрителя: каждый проскакивает чуть ближе плоскости экрана и встаёт на место; мимо камеры пролетают мелкие осколки.
- **0.65–1.8 с** — внешний контур метки рисуется по кругу.
- **1.75–4.1 с** — голубой круг становится вращающимся 3D-глобусом с меридианами, материками и мягким затенением, затем снова плоский.
- **2.55–4.4 с** — силуэт туриста получает объём, поворачивается к зрителю примерно на 35° и снова становится плоским.
- **4.05–5.6 с** — «МОЯ ПЛАНЕТА» появляется по буквам: каждая крутится и меняет размер, затем встаёт в строку между линиями.
- **6.0–7.05 с** — по всему логотипу слева направо проходит белый глянцевый блик.
- **7.05–8.0 с** — финальный кадр стоит.

Силуэт трассирован в вектор из исходного логотипа; надпись набрана Roboto Slab.
